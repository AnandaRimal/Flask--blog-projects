# 📝 Flask Complete Blog Project

## 📌 Project Overview

This is a **complete blog application built using Flask**, a lightweight Python web framework.  
It allows users to create, edit, delete blog posts, manage users, and supports login/logout functionality.

> Ideal for learning Flask basics and building a CRUD (Create, Read, Update, Delete) web app.

---

## 🚀 Features

- 🧾 Create, edit, and delete blog posts  
- 🔐 User authentication (Login & Logout)  
- 💾 SQLite database integration with SQLAlchemy  
- 📚 Jinja2 templating with HTML/CSS  
- 📦 Clean folder structure for scalability  
- ✅ Flash messages for user feedback

---

## 🧰 Tech Stack

- **Backend:** Python, Flask  
- **Frontend:** HTML, CSS, Bootstrap  
- **Database:** SQLite + SQLAlchemy ORM  
- **Others:** Jinja2 templates, Flask-WTF (forms)
